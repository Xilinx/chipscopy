chipscopy.HardenedDebugPCIe¶

class chipscopy.api.hardened_pcie.HardenedDebugPCIe(pcie_tcf)[source]¶

API wrapper for the CPM6 PCIe core.

Provides access to register properties, LTSSM state trace, and graph visualization for PCIe controllers.

get_dot()[source]¶

Returns the PCIe LTSSM graph in DOT format.

Graph topology is derived from the server’s encoding file. States are colored: orange=current, green=visited, gray=unvisited. Edge labels show transition counts.

get_plt()[source]¶

Renders the CPM6 Hardened Debug PCIe LTSSM graph as a matplotlib figure.

State node colors mirror the soft AXIS-PCIe convention:

  • orange – most-recently seen state (end of captured trace)

  • green – visited at least once during the trace

  • gray – not visited

The PCIe recovery path (L0→R.Lock→R.Cfg→R.Idle→L0, and the Gen3 equalization sub-path R.Lock→R.Eq→R.Speed→R.Lock) is drawn in blue so the hot path stands out at a glance — matching the blue-edge convention used by the soft AXIS-PCIe get_plt(). All other edges are black.

Visited edges are drawn thicker; unvisited edges are drawn thinner and lighter. Edge-transition counts appear as labels on each arrow; zero counts are suppressed for readability. A legend and the detected link speed/width are included in the figure.

Returns the matplotlib.pyplot module so the caller can do:

plt = pcie.get_plt()
plt.show()
# or: plt.savefig("ltssm.png", dpi=150, bbox_inches="tight")

get_trace_data()[source]¶

Returns the raw hex word list from LTSSM trace memory.

Each entry is a hex string like “0x00012345”. Integer entries from the server are normalized to hex strings. This is the simplest raw dump – no decoding is performed.

Return type:

is_link_up()[source]¶

Returns True if the PCIe link has reached L0 (trained).

LTSSM_STATE carries the raw state code rather than a name, so it is matched against every spelling of L0 the server may report: “0x11” from a register alias, “17” if it arrives as a decimal, and “l0” if a future encoding resolves it to a name.

Return type:

bool
